# AERIS Local Knowledge Database

Runtime database: `.aeris/knowledge/aeris.sqlite3` (gitignored, local-only).

`python -m aeris_runtime knowledge build` indexes versioned company/docs/skills/methods/standards/workflows/memory plus the read-only cached Core. `knowledge search` performs local retrieval without cloud sync.

Memory may evolve; Evidence remains separately governed and immutable according to AERIS trust rules.
