# Frequency Response Analysis

Deterministic local analysis of a validated FR CSV within a requested frequency band.

Outputs include average level, minimum/maximum, peak-to-peak spread, RMS deviation around the band mean, and frequency/level of extrema.

This baseline intentionally does not apply smoothing, psychoacoustic weighting, spatial averaging, target-curve normalization, tolerance masks, uncertainty propagation, or fixture/calibration correction unless a later version explicitly implements and tests them.

No LLM result is used for the numerical calculations.
