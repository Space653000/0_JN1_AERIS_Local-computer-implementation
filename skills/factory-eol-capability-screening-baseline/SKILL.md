# factory-eol-capability-screening-baseline

Use only for a declared process mean/standard deviation, spec limits, gage
repeatability/reproducibility standard deviation, and declared acceptance
thresholds. Computes the textbook Cpk against the declared spec limits and
the standard AIAG MSA percent-gage-R&R (gage standard deviation over total
standard deviation, part and gage variation combined in quadrature),
comparing both against declared thresholds. This does not perform a full
ANOVA gage R&R study from raw part/operator/trial data, execute a physical
measurement-system study, set the actual production EOL test limit, or
replace Human production sign-off.
