# doe-monte-carlo-design-screening-baseline

Use only for a declared design resolution (III, IV or V) and declared
causal-main-effect / model-validity claim flags. Requires design resolution
IV or higher before a causal main-effect claim is accepted (Resolution III
aliases main effects with two-factor interactions), and requires
independent validation before a model-validity claim is accepted (a small
Monte-Carlo standard error alone never establishes model correctness). This
does not verify the actual design-matrix alias structure, does not run any
Monte-Carlo simulation itself, and does not authorize a physical/production
decision.
