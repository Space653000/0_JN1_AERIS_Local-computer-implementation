# research-hypothesis-screening-baseline

Use only for declared replication-claim/independent-replication flags and a
declared raw-data-availability-disclosure flag. Requires an actual
independent replication before a replication claim is accepted -- a
citation count never satisfies this -- and requires raw-data availability
to always be explicitly disclosed rather than hidden behind an abstract
summary. This does not perform a full literature review and does not
authorize Human peer-review sign-off.
