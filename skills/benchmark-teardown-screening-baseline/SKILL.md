# benchmark-teardown-screening-baseline

Use only for declared SPL-matched-across-products and topology-claim/
validation flags. Requires SPL to be matched across all compared products,
and requires electrical validation before a visually inferred topology
claim is accepted. This does not cover a full product test-condition
matrix and does not authorize Human publication sign-off.
