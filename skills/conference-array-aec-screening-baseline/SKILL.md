# conference-array-aec-screening-baseline

Use only for a declared off-beam attenuation, AEC tail length, room path
length and declared acceptance thresholds. Checks the off-beam attenuation
against a declared maximum and the AEC-tail-over-room-path margin against a
declared minimum. This does not cover a full room/talker-position coverage
matrix, does not execute a physical instrument measurement, and does not
authorize Human production sign-off.
