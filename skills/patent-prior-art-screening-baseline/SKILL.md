# patent-prior-art-screening-baseline

Use only for declared novelty-verdict/claim-element-mapping flags and a
declared date type used for the comparison. Requires element-by-element
claim mapping before a novelty verdict is accepted -- keyword similarity
alone never satisfies this -- and requires the priority date, not the
publication date, to be used for prior-art comparison. This does not
perform a full claim chart and does not authorize Human legal sign-off.
