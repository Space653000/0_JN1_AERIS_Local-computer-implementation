# directional-mic-array-screening-baseline

Use only for a declared sidelobe suppression, array-geometry-symmetric
flag, unique-DOA-claim flag and ambiguity-resolution flag. Checks the
sidelobe suppression against a declared minimum independent of main-beam
width, and requires an explicit ambiguity-resolution mechanism before a
unique DOA claim is accepted from a symmetric array geometry. This does not
cover a full steering-angle coverage matrix, does not execute a physical
instrument measurement, and does not authorize Human production sign-off.
