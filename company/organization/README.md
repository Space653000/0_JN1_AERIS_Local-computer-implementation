# 100-Seat Organization

AERIS 的 100 席是 capability slots，不是 100 個常駐 process。

| Group | Seats |
|---|---:|
| Chief Council | 8 |
| Speaker CoE | 18 |
| Microphone CoE | 18 |
| Product Chiefs | 24 |
| Distinguished Experts | 20 |
| Engineering Operations | 12 |
| **Total** | **100** |

Task Router 每次依 Product × Discipline × Lifecycle × Evidence × Risk 動態選出約 5–15 個角色形成 Temporary Engineering Pod。

角色完整名稱與最新定義以 upstream `0_JN1_AERIS` read-only role library 為設計來源；本 repo 的後續工作必須把每個角色逐步落成可執行 role contract、Skill dependencies、tool permissions 與 acceptance rubric。
