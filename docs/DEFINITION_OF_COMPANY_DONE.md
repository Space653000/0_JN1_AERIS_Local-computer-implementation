# Definition of AERIS Company Done

AERIS 不因「程式能跑」就宣稱整間公司完成。

## Gates

- C0 Foundation — repository/manifest/installer/CI
- C1 Governance — constitution/risk/authority/core read-only boundary
- C2 Organization — 100 role contracts + dynamic pod routing
- C3 Knowledge — versioned Skills/Methods/Standards + local searchable DB
- C4 Engineering — Speaker/Mic × six disciplines workflows
- C5 Product — product playbooks / lifecycle
- C6 Trust — Evidence/Verification/Reproduction/Audit
- C7 Tools — CAE/lab/firmware adapters + version/calibration provenance
- C8 Experience — Dashboard/Workspace/Services linked to live truth
- C9 Operations — health/expected-run/backup/recovery
- C10 Portable Offline — clean-machine relocation, local model, no mandatory cloud
- C11 Privacy — local data egress deny verified; cloud ingress-only tests pass
- C12 Zero-Experience Install — supported machine can complete guided one-click bootstrap and produce deployment report
- C13 Business — service catalog / delivery / quality / human approval

## Hard acceptance targets

```text
Core repo unauthorized write                         0
Local private data automatic public-cloud egress    0
Offline configured-cloud calls                      0
False-Done                                           0
Unauthorized R3/R4 action                            0
Role registry count                                  100
Tier-A Evidence completeness                         100% applicable
Clean-machine relocation                             reproducible
Knowledge DB                                         local-only
Deployment report                                    generated
```

Unavailable proprietary software/hardware must report `NOT_CONFIGURED`, never fake `HEALTHY`.
