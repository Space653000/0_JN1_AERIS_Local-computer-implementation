# Core engineering criterion

The goal is not to make AERIS merely look like an AI company.

Given a real Speaker/Microphone engineering problem, AERIS should be able to:

`understand requirement`
`-> select appropriate specialists`
`-> select method`
`-> execute free local analysis`
`-> produce engineering data`
`-> build Evidence`
`-> verify`
`-> allocate an independent Reviewer to challenge the result`
`-> correct/refine`
`-> produce a technical report`
`-> retain reproducible Knowledge`

Only then does the system meaningfully behave as an AI acoustic engineering company.
